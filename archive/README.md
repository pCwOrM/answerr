# answerr Historical Site Archive

Bu dizin, answerr platformunun tarihsel sürümlerini ve akademik araştırma kayıtlarını korumak amacıyla depoda tutulan arşivlenmiş web sayfalarını barındırır.

Bu dosyalar kümülatif araştırma geçmişini korumak için depoda saklanmakta olup, canlı GitHub Pages yayın paketine **dahil edilmez** (`.github/workflows/pages.yml` yapılandırması ile dağıtım öncesinde hariç tutulur).

## Dizin İçeriği

- **`site/2026-10-13-v0.6/`**: answerr Pro ilk halka açık konsept ve prototip sürümü (13 Ekim 2026).
- **`site/2026-10-14-v1.2/`**: answerr Pro 1.2 sürümü — politika derleyicisi ve araştırma kütüphanesi (14 Ekim 2026).
- **`site/2026-10-15-root-v4.1/`**: Ticari Pro ana sayfaya taşınmadan önceki klasik araştırma ana sayfası (v4.1).
- **`site/research-portal/`**: Çift-biliş laboratuvarı ve klasik araştırma portalı kopyaları (`index.html`, `portal.html`).
- **`site/docs-v1.0.html`**: Yeni iki dilli geliştirici dokümantasyonu (`pro/docs.html`) ve `/v1/docs` öncesindeki ilk sürüm API dokümantasyonu.
