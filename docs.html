API REFERENCE v1.0.0

A.N.S.W.E.R.R. Reflex REST API

Dünyanın ilk 0-Byte VRAM ve Sistem-1 omurilik karar motoru için yüksek hızlı, deterministik REST arayüzü. Ağır LLM parametreleri ve devasa tensör matris çarpmaları yerine Mandelbrot sınır geometrisini kullanarak mikrosaniyeler içinde tip-güvenli refleks kararlar üretir.

< 0.5 ms Tipik Karar Gecikmesi
0 Bytes Kalıcı VRAM / Tensör Belleği
24 Bytes dM Sınır Koordinat Tohumu
100% Deterministik / Sıfır Halüsinasyon

Hızlı Başlangıç (Quickstart)

API tamamen açık ve anahtarsız (keyless) modda hizmet vermektedir. Herhangi bir kayıt gerekmeden doğrudan terminalinizden çağırabilirsiniz:

BASH / CURL 
curl -s -X POST https://api.answerr.me:4431/v1/decide \
  -H "Content-Type: application/json" \
  -d '{
    "question": "Yetkili yönetici API işlemine izin verilsin mi?",
    "state": {
      "user_role": "admin",
      "failed_attempts": 0,
      "req_frequency": 1.2
    }
  }'

Sunucu Adresi & Port Yapılandırması

PROD https://api.answerr.me:4431

Answerr üretim API kümesi, Apache SSL Reverse Proxy arkasında Port 4431 üzerinden güvenli HTTPS protokolü ile yayınlanmaktadır. Yazılımlarınızda istek atarken port numarasını (:4431) belirtmeyi unutmayınız.

Güvenlik & Hız Sınırları (Rate Limiting)

API'nin sürdürülebilirliği ve servis kalitesini garanti etmek amacıyla çok katmanlı koruma aktiftir:

  • IP Hız Sınırı (Rate Limit): İstemci IP adresi başına dakikada 60 istek (ortalama 1 req/s).
  • Patlama (Burst) Sınırı: 1 saniye içinde azami 15 istek. Bu eşiği aşan istekler anında 429 Too Many Requests ile yanıtlanır.
  • Gövde Boyutu Sınırı (Payload Size): Azami istek gövdesi 64 KB ile sınırlandırılmıştır. Daha büyük istekler 413 Payload Too Large ile reddedilir.
  • Dönen Hız Başlıkları: Her yanıtta kota durumu şeffaf olarak iletilir: X-RateLimit-Limit, X-RateLimit-Remaining, Retry-After.

POST /v1/decide

Çekirdek Sistem-1 refleks karar motoru. Verilen sistem durumu (state vector) ve soruları deterministik Mandelbrot sınır dinamiğiyle değerlendirir.

İstek Parametreleri (Request Body)

Parametre Tip Açıklama
state object Sistem operasyonel durum anahtarları (örn: user_role, failed_attempts, motor_temp).
question string (opsiyonel) Hızlı tekil soru dizesi.
domain string (opsiyonel) Tanımlı hazır domain: api_security, ddos_mitigation, financial_risk, robotics_industrial, ecommerce_fraud.
questions object (opsiyonel) Özel çoklu soru sözlüğü (noul, choice, score tiplerinde).

Örnek İstek (Domain Preset ile)

CURL 
curl -s -X POST https://api.answerr.me:4431/v1/decide \
  -H "Content-Type: application/json" \
  -d '{
    "domain": "api_security",
    "state": {
      "user_role": "attacker",
      "failed_attempts": 15,
      "req_frequency": 120.0
    }
  }'

POST /v1/systemone JevBench Wire Format

JevBench TypeSafe wire formatı için özel uç nokta. POST /v1/decide ile aynı WERR fraktal çekirdeğini kullanır; ancak soruları JevBench'in labels listesi formatında da kabul eder. Bu endpoint sayesinde JevBench benchmark koşucuları, Tau-Bench ajanları ve benzeri çerçeveler doğrudan WERR kararını test edebilir.

İstek Parametreleri (Request Body)

Parametre Tip Açıklama
task string (opsiyonel) Görev kimliği — yanıtta task_id olarak aynen döner.
state object Sistem durum vektörü. Risk skorları, anomali bayrakları vb. key-value çiftleri.
questions object Soru sözlüğü. Her soru için type (noul / choice / score) ve isteğe bağlı text alanı verilir.
JevBench formatı: labels: ["OPT_A", "OPT_B", ...] listesi.
Answerr formatı: criteria: {"opt_a": "Seçenek A", ...} sözlüğü.
İkisi de kabul edilir.
model string (opsiyonel) Model adı — yanıtta aynen döner. Varsayılan: werr-system-one.

Örnek İstek — JevBench Wire Format (cURL)

CURL — JevBench Labels Format 
curl -s -X POST https://api.answerr.me:4431/v1/systemone \
  -H "Content-Type: application/json" \
  -d '{
    "task": "jevbench-security-sample",
    "state": {
      "anomaly_detected": true,
      "risk_vector": [0.89, 0.12, 0.95, 0.04],
      "user_id": "usr_9921"

    "https://api.answerr.me:4431/v1/systemone",

POST /v1/chat/completions

Standart OpenAI Python SDK veya LangChain / LlamaIndex ile tak-çalıştır entegrasyon sağlayan adaptör uç noktasıdır. Hiçbir API anahtarı gerektirmeden mevcut projelerinizdeki OpenAI istemcisinin base_url adresini değiştirerek bağlayabilirsiniz.

Python OpenAI SDK Örneği

PYTHON 
from openai import OpenAI

client = OpenAI(
    base_url="https://api.answerr.me:4431/v1",
    api_key="werr-keyless-mode" # Anahtarsız modda dilediğiniz string geçerlidir
)

response = client.chat.completions.create(
    model="werr-reflex-v1",
    messages=[
        {"role": "system", "content": "Sen 0-Byte VRAM mikrosaniyelik karar motorusun."},
        {"role": "user", "content": "Kullanıcı admin rolünde, 0 başarısız deneme var. İstek onaylansın mı?"}
    ]
)

print(response.choices[0].message.content)

Doğrudan Yerel Python Entegrasyonu (pip install werr)

Ağ gecikmesi olmadan sıfır gecikmeli yerel çalıştırma için motoru doğrudan projenize gömebilirsiniz:

PYTHON (LOCAL EMBEDDED) 
from werr import WerrEngine, NoulQuestion, ChoiceQuestion

# 1. Sıfır VRAM / 24-byte tohum koordinatı ile motoru başlatın
engine = WerrEngine()

# 2. Durum ve soruları tanımlayın
state = {"user_role": "guest", "failed_attempts": 4, "req_frequency": 25.0}
questions = {
    "permit": NoulQuestion("İstek geçirilsin mi?"),
    "action": ChoiceQuestion("Aksiyon", {"pass": "Geçir", "captcha": "Captcha Göster", "block": "Engelle"})
}

# 3. Mikrosaniyede deterministik karar alın
verdict = engine.decide(state=state, questions=questions)
print("Sonuç:", verdict.answers["permit"].boolean)
print("Aksiyon:", verdict.answers["action"].choice)
